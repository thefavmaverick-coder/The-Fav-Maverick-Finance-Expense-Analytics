## 📌 About the Project

**The Fav' Maverick Finance & Expense Analytics** is a personal finance management website created to make everyday money tracking easier to understand and manage.

Instead of keeping financial details scattered across notes or spreadsheets, users can use a central dashboard to record transactions and review financial activity. Visual summaries and charts can help users notice spending patterns, compare income and expenses, and make more informed decisions about their money.

The website uses a modern black interface with neon-lime accents and is designed for desktop and mobile screens.

## 🧭 How to Use the Website

The exact screens and options may differ by version. A typical workflow is:

1. **Create an account or sign in** using the available authentication options.
2. **Open the dashboard** to review the financial summary.
3. **Add a transaction** and enter its amount, type, category, date, and any other requested details.
4. **Review your transaction history** to check that the information was recorded correctly.
5. **Explore the charts and analytics** to understand income and spending patterns.
6. **Use budgets and savings goals**, if available in your version, to organize your financial plans.
7. **Review reports or export data** using the supported options.
8. **Sign out** when using a shared device.

## ✨ Features

- **Personalized dashboard** — review key financial summaries in one place.
- **Income and expense tracking** — record transactions with amounts, categories, dates, and descriptions.
- **Transaction management** — review and manage recorded transactions.
- **Financial analytics** — explore financial trends and spending patterns with charts.
- **Budget management** — organize spending against budget limits.
- **Savings goals** — set and monitor progress toward financial targets.
- **Reports and exports** — access supported reports and export options.
- **Account authentication** — sign in or create an account using Supabase Auth.

- **Responsive interface** — designed to work across desktop and mobile screens.
